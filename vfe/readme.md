
The root directory here holds files that are generic across multiple theoretical tours. Thus, the current one launches from `palm_walk/vfe.html` and others would be `trip_name/vfe.html`. This way vfe.js is reused and I don't run into versioning problems across tours. Shared assets (icons) are also from this root directory. Project specific media are within the project subfolders.

Note that this vendors the main pannellum files. That's just how the html is coded so although it does duplicate them within this repo it might be best just to leave it for now.
